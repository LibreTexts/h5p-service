### Deployment notes

Every deployment-specific value is a required environment variable with no
default, and the service exits at startup naming the first one that is missing
or malformed. Set all of these before deploying:

`BASE_URL`, `MONGODB_URL`, `S3_CONTENT_BUCKET`, `S3_LIBRARY_BUCKET`,
`S3_TEMPORARY_BUCKET`, `AWS_REGION`, `AWS_ACCESS_KEY_ID`,
`AWS_SECRET_ACCESS_KEY`, `ALLOWED_EMBED_PARENT_ORIGINS`,
`EMBED_FRAME_ANCESTORS`, `EMBED_ADAPT_REFERRERS`,
`EMBED_TRUSTED_PARENT_HOSTS`.

`AWS_ACCESS_KEY_ID` and `AWS_SECRET_ACCESS_KEY` are required explicitly:
`@lumieducation/h5p-mongos3` does not fall back to an instance role or the AWS
SDK's default credential chain.

The attribution badge is opt-in. Without `EMBED_BADGE_HREF` no badge is
rendered, so a deployment that is not LibreTexts shows no LibreTexts branding.

See the Configuration section of README.md for the full table.
